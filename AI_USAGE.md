# AI Tool Usage Statement — GameVault Final PoE

AI tools were used as development assistance during the GameVault project. They were used to help explain Android Studio and Gradle errors, suggest Kotlin/Jetpack Compose implementation patterns, assist with debugging, review project structure, and help prepare documentation. AI assistance was also used to improve comments, README wording, release notes and troubleshooting instructions.

The generated suggestions were reviewed and adapted to the GameVault requirements before being included in the project. The student remained responsible for configuring Firebase, obtaining the RAWG API key, testing the application on an Android device, checking authentication and database behaviour, reviewing translations, running automated tests, and preparing the final GitHub and Play Store evidence.

Examples of AI-assisted work include the `debugRuntimeClasspathCopy` Gradle troubleshooting, Kotlin code structure for Firebase Storage profile-image uploads, FCM token handling, documentation, and test/build troubleshooting.
